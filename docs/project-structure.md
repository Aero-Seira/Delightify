# 项目结构

该文档描述了项目的文件结构和重要概念。

## 数据库架构

| 表名 | 描述 |
| ---- | ------ |
| users | 存储用户信息 |
| products | 存储产品信息 |
| orders | 存储订单信息 |


## 双层关系系统说明

在这个项目中，我们采用双层关系系统来处理数据与语义之间的关系。建议使用 `global.db` 作为基础数据库，并通过 `project.db` 进行覆盖，以满足特定需求。

### 多关系类型

每对实体可以具有多个关系类型。为确保数据的一致性，需要定义优先级与合并规则，以处理相同实体对之间的多个关系类型。

### 建议的载荷字段

在设计 API 端点时，我们建议包括以下字段以提高灵活性和可扩展性：
- `entity1` - 第一个实体的标识符
- `entity2` - 第二个实体的标识符
- `relation_type` - 关系类型
- `precedence` - 合并优先级
- `payload_fields` - 载荷字段的数组

请根据项目的具体需求调整这些字段。
